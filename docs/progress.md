### 第一轮已知的刻意简化

- **无富文本工具栏**：只支持标题 / 段落 / 粗斜体等基础 Markdown，表格与脚注不做往返保证。
- **单 Agent 串行**：同一时间只能跑一个任务（模块级 `activeSession`）。
- **跨文件提交是顺序写入 + 快照回滚**，不是真正的原子事务；进程崩溃时依赖快照恢复。
- **检索索引在内存中**，项目较大时打开会全量重建（20 万字以内可接受）。
- **无导出功能**（Markdown 本身就是导出格式）。
- **无自动更新**。
- **浏览器模式下 AI 不可用**（密钥与网络请求在 Rust 侧），会明确提示。
